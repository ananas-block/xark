# xark-client

Verify [xark](https://github.com/blueshift-gg/xark) zero-knowledge proofs and
build verifier calldata. Construct a client from the
[xark-wasm](../../crates/wasm/README.md) module and a circuit's verifying key
(`vk.bin`, from `xark setup`), then verify the proof bundles `xark prove`
produces.

```ts
import * as wasm from "@blueshift-gg/xark-wasm"; // web: `await init()` first
import { XarkClient } from "xark-client";

const client = new XarkClient(wasm, vkBytes); // vk.bin

const ok = client.verify(bundle);          // true / false
const data = client.calldata(bundle);      // packed proof ‖ public bytes
```

`bundle` is the `<name>-<hash>.proof.json` written by `xark prove` (it carries
the proof and public inputs as bytes and decimals, plus the calldata). The wasm
module is passed in, so any of xark-wasm's builds (Node, web, bundler, workers)
works.

## Verify vs. on-chain

- **verify** runs here, through xark-wasm, anywhere JavaScript runs.
- **calldata**: `calldata(bundle)` returns the packed `proof ‖ public_inputs`
  bytes (little-endian) a verifier consumes. You own the accounts and any
  instruction discriminator, so you build the transaction with your own client.
  The on-chain verifier itself is generated by `xark export`.

To prove in JavaScript as well, use xark-wasm's `prove`, or the typed client
`xark codegen ts` generates.

## API

- `new XarkClient(wasm, vk)` — `vk` is `vk.bin` (`Uint8Array` or `ArrayBuffer`).
- `verify(bundle)` / `verifyRaw(proofBytes, publicInputsBytes)` → `boolean`
- `calldata(bundle)` → `Uint8Array` (packed proof ‖ public inputs)
- `hexToBytes(hex)` → `Uint8Array`
